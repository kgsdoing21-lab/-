# 파주시 읍·면·동별 교회 현황 집계

카카오 로컬 API로 파주시의 교회를 수집해 행정 읍·면·동별로 집계하는 스크립트입니다.

## 배경
- 파주통계연보(제65회)에는 교회 수 표가 없습니다.
- 통계연보에서 찾은 비슷한 수치는 두 가지입니다.
  - 소방대상물 중 종교시설: 파주시 전체 178개소(2024년). 모든 종교가 포함됩니다.
  - 종교용지 면적: 법정동 기준입니다.
- 그래서 카카오 지도 검색 결과로 직접 집계합니다.

## 실행 준비
1. 카카오 개발자 센터에서 REST API 키를 발급합니다.
2. 클라우드 환경(Default)의 Environment variables에 `KAKAO_REST_API_KEY=<키>`를 추가합니다. `KakaoAK` 접두어는 붙이지 않습니다.
3. 환경의 허용 호스트에 `dapi.kakao.com`이 있어야 합니다(이미 추가됨).

## 실행
```bash
python3 paju_churches/kakao_churches.py <출력폴더>
```

## 결과 파일
- `paju_church_counts.csv`: 읍·면·동별 교회 수와 합계
- `paju_churches.csv`: 교회 목록(읍면동, 교회명, 카테고리, 지번·도로명 주소, 전화, 좌표)

## 방법과 한계
- '교회' 키워드 검색은 한 번에 최대 45건만 줍니다. 그래서 파주 영역을 결과가 45건 미만이 될 때까지 4등분하며 재귀적으로 검색합니다.
- 주소에 '파주시'가 있고, 카테고리가 기독교·교회인 장소만 남깁니다.
- 좌표를 행정동 코드(coord2regioncode, region_type H)로 변환해 읍·면·동을 정합니다.
- 카카오에 등록되지 않았거나 폐업 정보가 반영되지 않은 교회가 있을 수 있습니다. 한 건물의 여러 부서나 지교회가 따로 잡힐 수도 있습니다.
